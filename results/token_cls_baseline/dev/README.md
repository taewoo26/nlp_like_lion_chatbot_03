## 주요 해석과 한계

- Strict는 라벨·경계 완전 일치, Partial은 같은 라벨의 겹침을 순서대로 1:1 매칭한다.
- mask_rec은 문자 피복률이며 평가 대상 7종 예측만 입력했다.
- 오류 규모는 정답 단위 집계다. 경계 오류와 완전 미탐을 혼동하지 않는다.
- test·holdout 일반화와 전체 dev 반복 일관성은 미측정이다.
- 속도는 실행 시점이 다른 저장값으로 통제된 비교가 아니다.
