# 실전 2 규칙 검토 후 수정 기록

작성일: 2026-10-29 · 규칙 버전: `pii-basic-v3-review`

이번 작업은 규칙 설계서와 코드 비교에서 확인한 반례를 고치는 데 집중했다. 기존 DB 재적재, 볼륨 삭제, 외부 API 호출은 하지 않았다. 인물 해소·실명 복원·사용자별 접근 제어는 종합 단계 범위로 유지한다.

## 반영한 내용

| 항목 | 수정 전 반례 | 수정 후 확인 |
| --- | --- | --- |
| IBAN | 붙여 쓴 계좌 미탐, 공백 표기는 중간 숫자를 카드로 처리 | 국가코드부터 끝까지 계좌 하나로 탐지. 문서·질의 표기가 달라도 동일 토큰 |
| 회피 이메일 | 탐지는 되지만 `(at)` 때문에 정규화 오류 | 허용된 at/dot·골뱅이·닷·점 표기를 복원. 로컬 부분의 대소문자·기호 보존 |
| 전각 이메일 | 전각 영문자까지 포함하면 전체 미탐 | 탐지용 사본에서 전각 ASCII를 변환하고 원문 span으로 치환 |
| 이니셜 | `G. D. Hong`이 `GDHONG` 이름 토큰으로 변환 | 명시된 점 있는 이니셜은 정규화 전에 제외. 미정 혼합형은 확대 제외하지 않음 |
| 운전면허 | 같은 구간의 계좌 라벨이 남아 원문 매핑 생성 | 확인된 면허 라벨을 우선하여 고정 비공개 표시. 매핑·검색 토큰 없음 |
| 국내 주소 지역 표시 | `청구`, `가구`를 구 이름으로 간주 | 시도별 확인 목록과 대조. 확인되지 않은 부분은 치환 |
| 해외 주소 | `Main St`, `Los Angeles`만 이름으로 치환 | 영문 도로명·도시·지역 약자·5자리 우편번호 형식을 주소 전체로 치환 |
| 문서 간 충돌 | 저장 후 경고만 출력 | 임베딩·DB 호출 전에 중단. 같은 비교값의 다른 원문 표기는 허용 |
| 기존 Vault 충돌 | 정규화값이 달라도 originals 배열에 합침 | 라벨·정규화값 일치 조건이 충족돼야 갱신. 불일치하면 오류 |
| 저장 실패 | RAG가 먼저 커밋됨 | Vault 오류가 RAG 커밋 전에 전파되도록 연결 범위를 조정 |
| 오류 메시지 | 잘못된 Span의 원문까지 포함 | 원문 대신 span 인덱스만 기록 |

## 검색 기준

사용자가 이번 작업에서 선택한 기준은 **모든 토큰 일치, 없으면 결과 없음**이다. 이를 팀 전체의 승인 이력으로 소급하지 않는다.

질문에 개인정보 토큰이 있으면 문서 전체에서 모든 토큰을 포함한 문서만 의미 검색한다. 각 토큰이 서로 다른 청크에 있어도 같은 문서이면 후보가 된다. 일치 문서가 없으면 전체 의미 검색으로 되돌리지 않는다. 토큰이 없는 질문은 전체 의미 검색을 한다. 후보가 없으면 챗봇도 LLM을 호출하지 않고 문서를 찾지 못했다는 안내를 반환한다.

## 검증

실제 로컬 KoELECTRA·Veil·규칙 탐지기를 연결한 합성 반례 시험을 추가했다. 모델 파일이 없는 환경에서는 해당 통합 시험이 명시적으로 skip되며, 모델 다운로드를 자동 실행하지 않는다.

```bash
python -m pytest -q -p no:cacheprovider tests
```

현재 환경 결과: **190 passed**. 단위 시험, 실제 탐지기 통합 시험, 충돌·실패 전파 시험을 포함한다. 전체 데이터 탐지율이나 88개 질의 검색 점수가 아니다.

PostgreSQL에는 읽기 전용으로 연결했다. `WITH ... VALUES`로 만든 가상 청크에 실제 검색 SQL을 적용하여 다음을 확인했다.

- 같은 문서의 서로 다른 청크에 토큰이 나뉘어 있어도 후보가 됨
- 하나만 일치하는 다른 문서는 제외됨
- 일치 없는 질문은 빈 결과, 토큰 없는 질문은 전체 후보 검색
- `rag_user`의 Vault 스키마 접근과 `vault_user`의 RAG 스키마 접근이 차단됨

## 지원 범위와 남은 작업

- IBAN은 SWIFT Registry release 103의 국가별 길이를 사용한다. 은행코드·체크섬 유효성 검증기가 아니며, 체크섬 실패만으로 개인정보를 원문에 남기지 않는다. 줄바꿈으로 분절된 값을 추측해 합치지 않는다.
- 지역 표시 목록은 행정동 코드 공개 재배포본에서 시군구 297개 항목을 추출했다. 출처·원본 해시·수집일은 `starter/admin_regions.json`에 남겼다. 수집본의 최신 행 생성일은 2023-07-03이며 최신 행정구역 전체를 보장하지 않는다. 미등록 명칭은 가리는 쪽으로 처리하고, 목록 갱신을 별도로 관리해야 한다.
- 해외 주소 보강은 검증한 영문 형식에 한정된다. 모든 국가·언어의 주소를 탐지한다는 의미가 아니다. 그 밖의 미탐과 정책상 제외값은 여전히 남을 수 있다.
- 두 DB 연결의 완전한 원자성은 구현하지 않았다. Vault 커밋 후 RAG 커밋 자체가 실패하는 장애까지 해결하려면 별도 저장 설계가 필요하다.
- DB의 규칙 버전·key_id 기록과 조회 시 버전 불일치 차단은 남은 작업이다. 코드 버전 상수만으로 혼합 적재를 막을 수 없다.
- 기존 DB의 데모·이전 버전 데이터는 자동 변경하지 않았다. 버전과 키를 고정한 뒤 기존 결과를 보존하고 전체 재적재 및 88개 질의 평가를 진행해야 한다.
